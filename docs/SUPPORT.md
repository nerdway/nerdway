## Paid support

Paid support is help with using the installed plugin: questions about the workflow, tracker and VCS setup, upgrades, and troubleshooting.

Scope, hours, and response expectations are agreed per engagement. The MIT distribution does not include a service-level agreement.

## Paid onboarding

Paid onboarding is a structured engagement to get nerdway into a team's daily loop: connecting the tracker and the git host, walking the first issues from spec to merged pull request, and settling the habits the plugin expects (statuses as gates, the spec in the issue, an implementation-plan comment before code changes).

What that engagement includes is agreed up front. It is not a second license and it does not dual-license the source.

## Contact

Bugs, feature requests, and other public work on this repository go in [GitHub Issues](https://github.com/nerdway/nerdway/issues).

For paid support or paid onboarding, start from [Nerd4Rent](https://nerd4rent.io), or open a GitHub Issue that says you want a paid engagement. Details of an engagement are arranged from there.

GitHub Issues remains the public tracker for the project itself. It is not a substitute for a paid onboarding.
